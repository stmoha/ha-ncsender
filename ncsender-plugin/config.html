Each button sends a comment line such as (HA switch.shop_lights ON). The controller ignores it; the ncSender integration in Home Assistant switches the device, but only if the device is listed under Settings → Devices & services → ncSender → Configure → Devices ncSender may switch. Buttons don't work while a job is paused (ncSender holds all commands then) or with the controller disconnected.

One switch per line: Name, entity_id
